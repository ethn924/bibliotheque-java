# AP2 — Système de gestion de bibliothèque

Application Java (Swing) développée dans le cadre du BTS SIO SLAM (épreuve AP2).

## Fonctionnalités

- Gestion des emprunts et retours
- Recherche avancée d'ouvrages
- Génération de rapports
- Architecture MVC / DAO, persistance via JDBC + MySQL

## Stack

Java · Swing · JDBC · MySQL
